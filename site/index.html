Install PSManager

Pick whichever fits. All three routes ship the same installer and the same release.

irm https://raw.githubusercontent.com/danhthanh4182/psmgr/main/install.ps1 -OutFile .\install.ps1; .\install.ps1 -Method Winget -Silent

Installs from the winget community repository. Run psmgr afterwards to open the terminal UI.

irm https://raw.githubusercontent.com/danhthanh4182/psmgr/main/install.ps1 | iex

Run it inside PowerShell 7. The script checks the environment before downloading anything.

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/danhthanh4182/psmgr/main/install.ps1 | iex"

Frequently asked questions

Why does Windows SmartScreen warn me?

The installer is not code-signed yet, so SmartScreen may ask for confirmation. Choose More info, then Run anyway, after checking the SHA-256 digest against SHA256SUMS.txt in the release.

Do I need a GitHub account to install?

No. The repository and releases are public, so the installer downloads anonymously. A token (gh auth login or PSMGR_GITHUB_TOKEN) is only useful for private forks or to raise API rate limits; PSMGR_DISABLE_UPDATE_CHECK=1 turns the release check off entirely.

Does it run on Windows PowerShell 5.1?

Yes. Every module runs on Windows PowerShell 5.1 and PowerShell 7.4 or later, including the update check and the notification store.

How do I uninstall PSManager?

Use Settings, Apps, Installed apps. User state in %LOCALAPPDATA%\PSManager is kept; delete that folder for a clean removal.

Where do update notifications come from?

PSManager reads its own GitHub releases API at most once every six hours. Each check is one request; set PSMGR_DISABLE_UPDATE_CHECK=1 to disable it and PSMGR_DISABLE_TOASTS=1 to silence native toasts.
